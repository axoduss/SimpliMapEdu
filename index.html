⌨️ Scorciatoie da Tastiera

  • Tab - Aggiungi nodo figlio
  • Enter - Aggiungi nodo fratello
  • Canc / Backspace - Elimina nodo
  • Ctrl + N - Nuova mappa
  • Ctrl + S - Salva mappa
  • Ctrl + Z - Annulla
  • Frecce - Sposta tra nodi
  • + / - - Zoom avanti/indietro
  • Spazio + trascina - Panoramica
  • H - Mostra/nascondi aiuto
